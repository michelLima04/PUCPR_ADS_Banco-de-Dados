# Formação em Banco de Dados 🗄️⚡

Este repositório centraliza os projetos e estudos desenvolvidos durante a disciplina de **Banco de Dados para Tecnologia da Informação** do curso de Análise e Desenvolvimento de Sistemas da PUCPR. 

O objetivo principal desta trilha foi dominar o ciclo de vida completo de um banco de dados relacional: desde o entendimento da necessidade do negócio e modelagem conceitual até a administração avançada, segurança e automação via SQL.

## 🚀 Projetos em Destaque

O repositório está organizado em desafios práticos que simulam cenários reais de mercado:

### 1. [Atividade Somativa 1: Sistema de Delivery](./Atividade_01_Delivery/) 🍔
* **Foco:** Ciclo completo de design de dados (Conceitual, Lógico e Físico).
* **Destaque:** Mapeamento de requisitos de uma lanchonete, incluindo controle de cardápio, pedidos e logística de entregadores.

### 2. [Atividade Somativa 2: Gestão Vitivinícola](./Atividade_02_Vinhos/) 🍷
* **Foco:** SQL Avançado, Governança e Segurança.
* **Destaque:** Implementação de um banco de dados para vinhos e vinícolas com foco em controle de privilégios de acesso (DCL) e limites de consultas por usuário.

## 🛠️ Tecnologias e Conceitos Aplicados

Baseado no conteúdo programático da disciplina, este repositório demonstra proficiência em:

* **Modelagem de Dados:** Criação de Diagramas Entidade-Relacionamento (DER), definição de cardinalidades e aplicação de regras de normalização para eliminar redundâncias.
* **Linguagem SQL (MySQL/Oracle):**
    * **DDL (Data Definition Language):** Criação de esquemas, tabelas e definição de tipos de dados e chaves (PK/FK).
    * **DML (Data Manipulation Language):** Inserção, atualização e exclusão de registros (CRUD).
    * **DQL (Data Query Language):** Consultas complexas utilizando `INNER JOIN`, filtros avançados e funções de agregação.
    * **DCL (Data Control Language):** Gerenciamento de usuários e privilégios de segurança (`GRANT`/`REVOKE`).
* **Transações e Concorrência:** Aplicação das propriedades **ACID** para garantir a integridade dos dados em operações críticas.
* **Programação em Banco (Introdução):** Conceitos de automação através de `Views`, `Triggers`, `Functions` e `Stored Procedures`.
